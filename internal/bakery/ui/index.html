This local view only reads. Crumbs live as small Markdown files in memory/, so add one the way your team already works:

  1. Ask your agent. “Save that as a lesson in memory.” Baker’s instructions tell it how.
  2. Or write it yourself: one claim per file in memory/decisions/, lessons/ or knowledge/, with type, as_of, last_verified and source frontmatter, and a line in memory/MEMORY.md.
  3. Commit it with your code so teammates’ agents find it too.
